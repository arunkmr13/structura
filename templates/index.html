API Reference

      
Integrate Structura into your own app. One endpoint, multipart form data, JSON response.

    


    


      
      

        
Endpoint

        
POST /digitise

        
Accepts a whiteboard image and returns structured Mermaid code, a visual diagram, and raw JSON describing the extracted nodes and edges.

            Python
            
          

          
import requests

with open("whiteboard.jpg", "rb") as f:
    response = requests.post(
        "http://localhost:8000/digitise",
        files={"file": ("whiteboard.jpg", f, "image/jpeg")}
    )

if response.status_code == 200:
    data = response.json()
    print("Mermaid code:")
    print(data["mermaid"])
    print(f"\nModel used: {data['model_used']}")
    print(f"Nodes: {len(data['raw']['nodes'])}")
    print(f"Edges: {len(data['raw']['edges'])}")
else:
    print(f"Error {response.status_code}: {response.json()['detail']}")

Endpoint

        
POST /chemistry

        
Accepts a chemical formula or molecule name and returns a 2D structural diagram image, SMILES notation, and molecular metadata.


        

          POST
          /chemistry
          
        


        

          Want to explore interactively? Try the built-in
          Swagger UI →
        

      


      
      

        
Request

        
Parameters

        
Accepts JSON body — not multipart form data like /digitise.


        

          
            
FieldTypeRequiredDescription

          
          
            

              formula
              string
              required
              Chemical formula (e.g. H2O), common name (e.g. caffeine), or IUPAC name. Max 200 characters.
            

            

              style
              string
              optional
              Diagram style — "skeletal" (default) or "lewis". Skeletal shows bonds only with carbons implied. Lewis shows all atoms including hydrogens explicitly.
            

          
        

      


      
      

        
Examples

        
Code Samples


        

          
          
          
        


        

          

            curl
            
          

          
# Skeletal diagram of caffeine
curl -X POST http://localhost:8000/chemistry \
  -H "Content-Type: application/json" \
  -d '{"formula": "caffeine", "style": "skeletal"}'

# Lewis diagram of water
curl -X POST http://localhost:8000/chemistry \
  -H "Content-Type: application/json" \
  -d '{"formula": "H2O", "style": "lewis"}'

        


        

          

            Python
            
          

          
import requests
import base64

response = requests.post(
    "http://localhost:8000/chemistry",
    json={"formula": "aspirin", "style": "skeletal"}
)

if response.status_code == 200:
    data = response.json()

    # Save the image
    image_data = data["image"]
    if image_data.startswith("data:image/png;base64,"):
        png_bytes = base64.b64decode(image_data.split(",")[1])
        with open("molecule.png", "wb") as f:
            f.write(png_bytes)
        print("Image saved to molecule.png")

    print(f"SMILES: {data['smiles']}")
    print(f"Model used: {data['model_used']}")
    print(f"Formula: {data['metadata']['molecular_formula']}")
    print(f"Weight: {data['metadata']['molecular_weight']}")
    print(f"Description: {data['metadata']['description']}")
else:
    print(f"Error {response.status_code}: {response.json()['detail']}")

Documentation

      
How it works

      
Everything you need to get the best results from Structura — pipeline internals, supported formats, and tips from real usage.

    


    


      
      

        
Pipeline

        
Three-stage processing

        
Every image goes through three stages before you see a result. Understanding each stage helps you know why results vary and how to improve them.


        


          

            

              
            

            

              
Stage 1

              
Image Preprocessing

              
The raw photo is cleaned up using OpenCV before anything else happens. This includes resizing large images, converting to grayscale, denoising with a Gaussian filter, and applying adaptive thresholding to make the diagram lines pop against the background. This stage is why Structura can handle badly-lit or slightly blurry photos.

              

                OpenCV
                Pillow
                Adaptive Threshold
              

            

          


          

            

            cleaned image
          


          

            

              
            

            

              
Stage 2

              
Gemini Vision Extraction

              
The cleaned image is sent to Gemini Vision as a base64-encoded JPEG along with a structured prompt. The model identifies every shape (node), arrow (edge), label, and diagram type. It returns a strict JSON object with nodes and edges. If the primary model is unavailable, the system automatically falls back through the model chain.

              

                gemini-2.5-flash
                Structured JSON
                Model Fallback
              

            

          


          

            

            nodes + edges JSON
          


          

            

              
            

            

              
Stage 3

              
Mermaid Rendering

              
The JSON is converted to valid Mermaid syntax. Each node shape maps to its Mermaid equivalent — rectangles become [ ], diamonds become { }, circles become ([ ]). Labels are sanitised to remove special characters that break Mermaid's parser. The output renders live in the browser using Mermaid.js, and is also available as copyable code or a downloadable .md file.

                graph TD
                Label Sanitisation

Best Practices

        
Tips for best results

        
Small changes to how you draw and photograph your diagrams make a significant difference in extraction accuracy.


        

          

            
📸

            
Shoot straight-on

            
Position your camera directly in front of the whiteboard — not at an angle. Perspective distortion makes shapes harder to identify correctly.

          

          

            
💡

            
Even lighting

            
Avoid direct light sources that cause glare on the whiteboard surface. Natural diffused light or indirect room lighting works best.

          

          

            
✏️

            
Clear, bold shapes

            
Use a dark marker and draw shapes with clear, closed boundaries. Boxes, diamonds, and ovals with definite edges extract much more reliably than sketchy lines.

          

          

            
→

            
Obvious arrow direction

            
Draw arrowheads that are clearly visible and directional. Ambiguous lines without arrowheads may be interpreted as edges with uncertain direction.

          

          

            
🔤

            
Short labels

            
Keep node labels to 3–5 words maximum. Labels that overflow their shapes or overlap arrows are harder to associate with the correct element.

          

          

            
🧹

            
Clean whiteboard

            
Erase old diagrams completely before drawing a new one. Ghost marks from previous drawings confuse the model and produce extra phantom nodes.

Molecules Pipeline

        
Chemistry — how it works

        
The Molecules feature follows a different pipeline from the diagram digitiser. Instead of image preprocessing, it starts with a text input and uses Gemini as a chemistry knowledge engine before handing off to RDKit for validated rendering.


        


          

            

              
            

            

              
Stage 1

              
Formula Interpretation

              
Your input — whether a formula like C6H12O6, a common name like caffeine, or an IUPAC name — is sent to Gemini with a strict prompt asking for a canonical SMILES string plus molecular metadata. Gemini acts as a chemistry knowledge engine here, not a vision model.

              

                Gemini Text
                SMILES Generation
                JSON Output
              

            

          


          

            

            SMILES string + metadata
          


          

            

              
            

            

              
Stage 2

              
RDKit Validation

              
The SMILES string from Gemini is passed to RDKit — an open-source cheminformatics library — which attempts to parse and validate it. If the SMILES is invalid or chemically impossible, RDKit rejects it and the request fails with a clear error rather than silently rendering a wrong structure. This validation step is critical because Gemini occasionally hallucinates SMILES for complex molecules.

              

                RDKit
                SMILES Validation
                2D Coordinate Generation
              

            

          


          

            

            validated molecule object
          


          

            

              
            

            

              
Stage 3

              
2D Structure Rendering

              
RDKit computes 2D coordinates for the molecule and renders it as an SVG using its built-in drawing engine. For skeletal style, carbon atoms are implied at bond intersections. For Lewis style, all hydrogens are added explicitly before rendering, showing every atom in the molecule. The SVG is converted to PNG via cairosvg and returned as a base64 data URI.

              

                RDKit MolDraw2D
                SVG → PNG
                cairosvg

Molecules Best Practices

        
Tips for best results


        

          

            
🧪

            
Use common names for drugs

            
Type "aspirin" not "2-acetoxybenzoic acid". Common names give Gemini an unambiguous target and reduce hallucination risk on complex IUPAC strings.

          

          

            
⚗️

            
Skeletal for complex molecules

            
For molecules with many atoms, skeletal mode produces a cleaner, more readable diagram. Lewis mode with explicit hydrogens gets very crowded above ~20 heavy atoms.

          

          

            
🔬

            
Verify with SMILES tab

            
Always check the SMILES tab after generation. If the structure looks wrong, copy the SMILES into PubChem or MolView to verify before using the image.

          

          

            
📐

            
Lewis for teaching

            
Lewis style is best for educational use — it shows every hydrogen explicitly, making bond counting and electron pair identification straightforward for students.

          

          

            
🔗

            
Use SMILES for further work

            
Copy the generated SMILES into MolView for a 3D ball-and-stick view, PubChem for full compound data, or Ketcher to edit the structure interactively.

          

          

            
♻️

            
Retry on wrong structures

            
If the generated structure looks incorrect, hit Retry — Gemini may return a different SMILES on the next call. Consistent wrong results usually mean the input is ambiguous.

Limitations

        
Known limitations

        
Structura works well on most diagrams but has known constraints worth understanding before you rely on it.


        

          

            
⚠️

            

              
Cyclic diagrams may not render visually

              
Mermaid's layout engine occasionally fails on diagrams with loops or back-edges (like bubble sort). The Mermaid code is still correct — use mermaid.live to render it.

            

          

          

            
⚠️

            

              
Special characters are simplified

              
Labels containing math expressions, code syntax, or special characters (< > [ ] { } = +) are converted to plain English to keep the Mermaid output valid.

            

          

          

            
⚠️

            

              
Free tier rate limits

              
The Gemini free tier has daily and per-minute request quotas. If all models are exhausted, requests will fail until the quota resets. Quotas reset at midnight Pacific Time.

            

          

          

            
⚠️

            

              
Accuracy varies with image quality

              
Very messy, low-contrast, or angled photos produce less accurate extractions. The preprocessing stage helps but cannot fully compensate for poor source images.

            

          

          

            
⚠️

            

              
No layout preservation

              
Mermaid handles its own layout automatically. The spatial arrangement of nodes in your original sketch is not preserved — only the logical structure (connections and labels) carries over.
